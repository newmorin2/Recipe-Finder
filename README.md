# Recipe Finder 

A React application that allows users to search for recipes, explore different food categories, and view detailed cooking instructions and ingredients.

## Features

- **Fetch Recipes:** Retrieve recipes from TheMealDB API.
- **Search Recipes:** Search for recipes by name.
- **Filter by Category:** Filter recipes by categories such as Chicken, Seafood, Dessert, and Pasta.
- **Recipe Details:** View individual recipe information.
- **Cooking Instructions:** View step-by-step cooking instructions.
- **Loading & Error States:** Display loading messages and handle API errors.

## API

This project uses [TheMealDB API](https://www.themealdb.com/api.php) to retrieve recipe information.

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/newmorin2/Recipe-Finder.git
   ```

2. Navigate into the project folder:

   ```bash
   cd recipe-finder
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL provided in your terminal.

## Learning Objectives

This project was developed to practise working with external APIs in React, managing component state, filtering data, handling asynchronous operations, and dynamically displaying information from API responses.
